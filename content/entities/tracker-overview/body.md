# Tracker: a local research workspace

Tracker is designed to keep useful research in reviewable, durable files while
showing a deliberately selected browser projection. The repository—not the
website—is the source of truth. This owner-maintained introduction describes
the intended operating model; it is not a report of completed source research.

## Start here

- Browse topics to find a bounded area of work.
- Open an entity to read the current explanation and its relationships.
- Use local search for titles, summaries, topic labels, tags, and safe body text.
- Check research state before attempting a refresh. Unverified does not mean
  failed, and a failed attempt must not replace the last verified conclusion.

See [the independent data/view architecture](#/entities/tracker-data-view-architecture)
for the boundary between persisted meaning and reusable presentation.
