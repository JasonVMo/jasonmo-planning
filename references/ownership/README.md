# Central ownership

Only owner-reviewed `policies.yaml` grants permissions. Descriptors reference
policy IDs but cannot broaden them. Reconciliation admits only the schema's
closed JSON Pointer allowlist, named body regions, and named research files.
IDs, data contracts, sensitivity, publication, ownership, refresh configuration,
and lifecycle remain owner-controlled. Taxonomy, policies, approvals, code,
new entities, deletion, and schema migrations are not agent promotion targets.

The mixed policy allows research-summary text and selected summary/provenance/
relationship/review fields. Manual text and marker bytes must match exactly.
Expected SHA-256 hashes cover every touched original file; stale hashes block
the complete proposal. Formatter changes inside manual text are not an excuse.
