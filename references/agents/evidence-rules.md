# Evidence and continuation rules

- **Observed:** directly checked against a cited source.
- **Inferred:** reasoned conclusion with cited premises.
- **Recommended:** proposed design or action, not an observed fact.
- **Confirmed:** explicit source-owner answer.

Record source IDs, publisher, access, retrieval timestamp, revision/fingerprint,
and material claim links. Do not fabricate research, successful timestamps, or
reviewer authority. Evidence manifests and run outcomes are concise; raw
transcripts, stack traces, machine paths, credentials, and downloads are excluded.

State tracks objective, completed/remaining scope, cursors, attempts, successes,
review, questions, contradictions, retry eligibility, and next action.
Freshness comes only from successful verification and explicit report time.
A failure never refreshes facts; partial work cannot mark the whole topic
verified. Preserve the previous successful event and expose uncertainty.
